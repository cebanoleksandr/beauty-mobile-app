Icons in this folder are NOT exported from Figma — the design has no equivalent.
They reuse the outline path of `../bookmark.svg` (the design's card "favorite"
icon) so they match the rest of the icon set.

- `client-inactive.svg` / `master-active.svg` — recoloured copies of
  `settings/client.svg` / `settings/master.svg` (Figma 7:2039 / 7:2043): the
  design only shows Client active and Master inactive, so the opposite states
  reuse the same paths with the other state's colour.
